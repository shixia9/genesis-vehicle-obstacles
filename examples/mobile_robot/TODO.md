# mobile_robot 开放词汇自然语言导航 TODO

> 最终目标：用户用自然语言描述场景中的目标或地点，例如“行驶到黄色小车附近”“去绿色柱子后面的平台旁边”，系统能够理解指代、在车载视觉中主动搜索和确认目标、估计目标三维位置、规划安全路线并停车。
>
> 本文取代“不断增加 YOLO 闭集类别”作为后续主线。现有闭集 YOLO 保留为已完成基线、回归工具和可选辅助检测器，不再承担任意自然语言目标的核心解析职责。
>
> 相关文档：[TASK.md](TASK.md)、[TASK_LLM.md](TASK_LLM.md)、[EXECUTION_REPORT.md](_reports/EXECUTION_REPORT.md)。

## 0. 方向调整

当前闭集模型只学习了 `car`、`box_obstacle`、`cylinder_obstacle`，每类外观、颜色和场景变化有限。即使继续增加 `pillar`、`platform` 等类别，也只能扩大类别表，无法支持用户描述新的物体、属性组合和空间关系。

后续架构调整为：

```text
用户自然语言
    │
    ▼
LLM 任务解析
  - 保留原始指代表达
  - 解析动作/属性/关系/约束
    │
    ▼
开放词汇视觉指代解析
  - 文本提示目标检测
  - 候选区域/分割 mask
  - 属性与空间关系验证
    │
    ▼
多帧确认 + RGB-D 三维定位 + 语义记忆
    │
    ├── 多候选：请求用户澄清
    ├── 未找到：主动旋转/搜索
    └── 已确认：输出目标世界坐标
    │
    ▼
目标附近安全姿态 + 2D 路径规划
    │
    ▼
waypoint 跟踪 + LiDAR 最高优先级安全层
    │
    ▼
ARRIVED / TARGET_NOT_FOUND / AMBIGUOUS_TARGET / FAILED
```

## 1. 不再采用的做法

- [X] 不把“为每个新名词增加一个 YOLO 类别”作为实现任意语义的主要方案。
- [X] 不要求 LLM 把未知名词错误映射到已有闭集类别。
- [X] 不让 LLM/VLM 直接输出轮速、路径节点或控制代码。
- [X] 不用 Genesis 真值类别和位置参与运行时目标选择。
- [X] 不把低置信度开放词汇匹配直接当作导航目标。
- [X] 不在目标不存在或存在歧义时随机选择目标。

## 2. 当前可复用基线

- [X] 运动学小车、waypoint 跟踪和 LiDAR 安全层。
- [X] 车载 RGB/Depth/LiDAR/IMU/位姿采集。
- [X] Genesis RGB-D 已知内外参标定和世界坐标转换。
- [X] 多帧跟踪、颜色属性、距离估计、日志和实时标注窗口。
- [X] 闭集 YOLO 数据生成、训练、独立 test 和运行回归。
- [X] 1126 步到达、0 碰撞、45/45 推理、26 个检测的闭环基线。

需要替换或扩展的核心是“目标语义从哪里来、如何和图像区域对齐”，而不是重写底层相机、深度、LiDAR 和运动控制。

## 5. 分阶段交付计划

### Phase 0：技术决策门

交付：本地预训练权重政策、YOLO-World 主模型可行性报告和冻结指标；替代模型评估不作为当前阶段前置条件。

只有候选模型在 Genesis OOD 短语测试中证明可用后，才进入完整导航开发。

### Phase 1：开放词汇视觉最小闭环

交付：终端输入文本 prompt，车载画面返回正确候选框/mask；支持目标不存在和多候选，不控制车辆。

### Phase 2：主动搜索与三维目标确认

交付：目标不在初始视野时小车可旋转搜索，候选经多帧和 RGB-D 确认，输出稳定世界坐标。

### Phase 3：Fake TaskSpec 语义导航

交付：不接真实 LLM，由固定开放指代 TaskSpec 驱动停车姿态、A*、waypoint 和 LiDAR 安全控制。

### Phase 4：LLM 与终端集成

交付：自然语言解析、必要澄清、状态反馈、stop/cancel 和全链路日志。

### Phase 5：真实 API 与验收

交付：真实 LLM、超时/断网/非法输出测试、10 个以上固定 seed、多目标和未见语义任务回归、演示视频和最终报告。

## 6. 最终验收标准

- [ ] 用户可以使用未出现在原闭集 YOLO 类别表中的目标描述。
- [ ] 系统保留并 grounding 完整指代表达，不只解析一个名词。
- [ ] 目标存在时选中正确区域；不存在时明确失败；多候选时请求澄清。
- [ ] 目标不在初始视野时能够主动搜索。
- [ ] 只有多帧确认且三维位置有效的目标才能进入规划。
- [ ] 路径、轮速和安全动作全部由控制侧产生。
- [ ] LiDAR 始终拥有最高安全优先级。
- [ ] 到达后满足停车距离、朝向、零速度和无碰撞条件。
- [ ] LLM/VLM/API 任一故障都不会产生未授权车辆动作。
- [ ] 日志可以完整复盘自然语言、视觉 prompt、候选、目标选择、路径和最终状态。

## 7. 开始实施前必须确认

1. 是否允许引入和本地保存开放词汇视觉语言预训练权重；
2. 可接受的模型许可证、权重来源和部署方式；
3. 目标设备仍为 CPU，还是允许 MPS/CUDA；
4. 首期是否允许使用 Genesis 已知静态地图做路径规划；
5. 多候选澄清使用纯终端编号、截图选择还是图形界面；
6. 是否允许向云端 LLM 发送候选摘要或静态截图；
7. “附近”的物理距离口径和默认安全距离。
